LumaPet

Blog técnico | Proyecto final

Aprendizaje, comunicación y mejora continua en entornos digitales.

1. Contexto

LumaPet es una empresa ficticia dedicada a desarrollar soluciones digitales para facilitar el cuidado y el bienestar de las mascotas. Para este proyecto se propuso crear una página informativa sencilla y publicarla en internet utilizando GitHub como plataforma de trabajo.

El objetivo fue aplicar conocimientos básicos de HTML, organización de archivos, control de versiones y comunicación digital.

2. Problema

El principal desafío técnico consistió en crear una página web correctamente estructurada y preparar el proyecto para su publicación. Al comenzar, fue necesario familiarizarse con la interfaz de GitHub, identificar el archivo principal de la página y comprender cómo registrar los cambios.

Sin un procedimiento ordenado, existía el riesgo de modificar archivos equivocados, perder avances o no poder identificar qué cambios se habían realizado.

3. Acciones y post-mortem constructivo

Se creó un repositorio público llamado lumapet-blog y se incorporó el archivo index.html como página principal. Después, se revisó el contenido para organizarlo en secciones y mejorar su presentación visual.

Los cambios se registraron mediante commits con mensajes descriptivos. El siguiente paso del proceso es configurar GitHub Pages y comprobar que la página sea accesible desde una URL pública.

Post-mortem constructivo: la principal dificultad fue comprender la secuencia de acciones necesarias para editar, guardar y publicar el sitio. Para mejorar el proceso, se decidió avanzar paso a paso, verificar cada etapa antes de continuar y utilizar nombres claros para los archivos y los commits. Esta revisión permite aprender de las dificultades sin convertir los errores en críticas personales.

4. Aprendizajes

El proyecto permitió comprender que el desarrollo web no consiste únicamente en escribir código. También requiere organización, pruebas, documentación y una secuencia de trabajo clara.

Se aprendió que un repositorio público facilita compartir el proyecto y que los commits ayudan a reconstruir su evolución. También se identificó la importancia de verificar el resultado publicado antes de dar una tarea por terminada.

5. Control de versiones y evidencias

El proyecto se gestiona mediante un repositorio de GitHub. Cada commit registra un conjunto de cambios y permite consultar cómo evolucionó el trabajo.

Repositorio: lumapet-blog.

Los enlaces directos al repositorio y a los commits se incorporarán una vez verificados, para que cualquier lector pueda consultar las evidencias del proceso.

6. Reflexión sobre el feedback radicalmente sincero

El feedback radicalmente sincero implica comunicar observaciones concretas con respeto y con la intención de mejorar el resultado. En este proyecto, una observación útil sería señalar que la página necesita una estructura más clara o que todavía falta verificar su publicación, en lugar de limitarse a decir que el trabajo está mal.

La respuesta adecuada es analizar la observación, identificar qué se puede mejorar y realizar una corrección concreta. De esta manera, el feedback se convierte en una herramienta de aprendizaje y no en un ataque personal.

7. Conclusión

La experiencia con LumaPet muestra cómo un proyecto digital puede avanzar mediante objetivos pequeños, revisión constante y documentación de los cambios. La mentalidad de crecimiento permite reconocer las dificultades, aprender de ellas y mejorar progresivamente.

La publicación del sitio y la verificación de su acceso público serán las comprobaciones finales para completar el proceso.
