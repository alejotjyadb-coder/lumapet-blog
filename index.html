LumaPet

Blog técnico — Proyecto Final

Contexto

LumaPet es una empresa ficticia orientada a ofrecer soluciones digitales para el cuidado y bienestar de mascotas. Como parte de un proyecto digital, se planteó la creación y publicación de una página web informativa utilizando herramientas de desarrollo web y control de versiones.

Problema

Durante el desarrollo surgieron dificultades para organizar correctamente los archivos del proyecto y publicar la página de forma accesible. También fue necesario aprender a utilizar un sistema de control de versiones para registrar los cambios realizados y evitar perder avances.

Acciones

Se creó un repositorio público en GitHub para centralizar el proyecto. Luego se incorporó la estructura inicial de la página y se documentaron los cambios mediante commits.

Como parte del post-mortem constructivo, se revisaron las dificultades encontradas durante el proceso, especialmente la organización de los archivos y la necesidad de realizar cambios de manera ordenada y documentada.

Aprendizajes

El principal aprendizaje fue comprender que el control de versiones permite trabajar de manera más segura y organizada. Registrar cada modificación facilita identificar errores, recuperar versiones anteriores y comprender cómo evolucionó el proyecto.

Control de versiones

El proyecto utiliza GitHub como sistema de control de versiones. Los commits permiten documentar la evolución del proyecto y evidenciar las diferentes etapas del trabajo.

Feedback radicalmente sincero

Durante el proceso se incorporó feedback directo para identificar aspectos que podían mejorarse. En lugar de interpretar las observaciones como una crítica personal, se utilizaron como una oportunidad para detectar errores, ordenar mejor el trabajo y mejorar el resultado final.

Conclusión

El desarrollo de LumaPet permitió aplicar conceptos de mentalidad de crecimiento, comunicación y mejora continua en un entorno digital. El uso de GitHub permitió además documentar la evolución del proyecto de manera concreta.
